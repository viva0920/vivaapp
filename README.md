# 🍓 小熊工作台（手机版）

一个可爱风的 iPhone 工作台，含三大模块：🧾 记账、🥗 减肥、🧁 烘焙。
纯前端（HTML + CSS + JS），**无需任何服务器、无 CDN 依赖、离线可用**。

## 文件说明
- `index.html` —— 主页面
- `style.css`  —— 可爱粉嫩风格样式
- `app.js`     —— 全部逻辑（数据存浏览器 localStorage / IndexedDB）

## 怎么部署（任选其一，都是 24h 不掉线）
把这三个文件（加上本说明）一起上传到任意**静态网站托管**即可：

1. **GitHub Pages**：新建仓库 → 上传这三个文件到根目录 → Settings → Pages → 选 main 分支根目录 → 得到 `https://你的用户名.github.io/仓库名/`
2. **Vercel / Netlify**：拖文件夹进去，零配置自动上线
3. **腾讯云对象存储 COS / 阿里云 OSS**：开启「静态网站托管」，把文件传上去
4. **自己的服务器 / 任意支持静态文件的空间**：直接放进去就行

## 手机使用
用 Safari / Chrome 打开上面的链接 → 点「分享 → 添加到主屏幕」，桌面上就有图标，全屏无地址栏，体验跟 App 一样。

## 重要提醒
- 数据保存在**打开网站的那个浏览器**里；换设备 / 换浏览器不会自动同步。
- 建议偶尔用「导出备份」功能（如果有）或截图备份重要数据。
- 视频类功能（减脂餐 / 运动 / 烘焙教程）是跳转 B站搜索链接，需联网。
